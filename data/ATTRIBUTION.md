# Dataset attribution

Janosi, A., Steinbrunn, W., Pfisterer, M., & Detrano, R. (1989). **Heart Disease** [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C52P4X

Source: https://archive.ics.uci.edu/dataset/45/heart+disease

UCI lists the donation date as 30 June 1988 but supplies **1989** in its recommended citation. This project follows the recommended citation year.

License: Creative Commons Attribution 4.0 International (CC BY 4.0), https://creativecommons.org/licenses/by/4.0/ . The original processed Cleveland file is preserved. Changes in the cleaned version: named columns, numeric parsing, missing-value normalization, binary target mapping (`num > 0`) and duplicate checking. No original rows were removed because no exact duplicates were found. The original creators do not endorse this implementation.
